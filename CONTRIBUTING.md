# Contributing

Changes to these standards should be proposed through a pull request.

Explain:

- What requirement or guidance changes.
- Which repository classes or lifecycle states are affected.
- Why the change creates value.
- Which existing practice or repository experience supports it.
- Whether adoption requires repository migrations or organization-setting changes.

Normative changes must update `CHANGELOG.md`. Use UTC dates in `YYYY-MM-DD` form. Do not rename existing repositories or packages as an incidental part of a standards change.
